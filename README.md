# Java y backend

Repositorio de prácticas de Java con un proyecto de API de productos desarrollado con Spring Boot y Maven.

## Proyecto principal

[Explorar la API de productos](./CrusoJava/curso_java-main/productoapi)

La API organiza el código en controladores, servicios y repositorios, como práctica de separación de responsabilidades en el backend.

## Estructura

- `CrusoJava/curso_java-main/productoapi`: proyecto de la API.
- `CrusoJava/curso_java-main/productoapi/pom.xml`: configuración y dependencias.
- `CrusoJava/curso_java-main/README.md`: documentación del material de curso.

Para abrir la API en un IDE, importá su `pom.xml` como proyecto Maven.
