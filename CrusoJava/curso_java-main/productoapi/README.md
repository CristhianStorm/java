# Productos API

API REST educativa con Java 21, Spring Boot 3.4.5, Spring Data JPA y H2 en memoria.

La [guía completa del repositorio](../../../README.md) incluye arquitectura, requisitos, endpoints, ejemplos y limitaciones.

Desde esta carpeta, con JDK 21 y Maven instalado:

```bash
mvn spring-boot:run
```

Consultar: `http://localhost:8480/api/productos`. La persistencia en memoria se reinicia con la aplicación.
